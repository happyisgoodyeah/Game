# 前三关环境美术

## 2026-11-01：独立环境动画层

前三关现在使用独立环境预制体。运行资源位于 `Resources/LevelScenes/Animated/`，`Environment1001.prefab`、`Environment1002.prefab`、`Environment1003.prefab` 分别配置三关的装饰与天气。原有背景图片保留；首关改用移除窗帘和两盆植物后的 `room-static.png`，再将独立物件叠回，避免摆动时出现双重轮廓。

| 关卡 | 动画 | 默认节奏 |
| --- | --- | --- |
| 1001 | 左右窗帘轻摆，窗台与置物架的盆栽随风摆动 | 四个独立网格；窗帘上缘、花盆底部或盆身区域固定 |
| 1002 | 樱花从右上树冠附近缓慢飘落并翻转 | 24 个对象循环复用，保持稀疏分布 |
| 1003 | 风将露台下半部的落叶带过画面 | 8 个对象复用；默认每 16 秒一阵风，单片飘动 6 秒，阵风之间保持安静 |

环境预制体使用以下结构：

```text
EnvironmentLayers
├── AnimatedDecor                 独立窗帘、盆栽等可动画物件
├── Weather                       樱花或落叶的固定对象池
└── PuzzleProps                   不参与环境动画的解谜物件挂点
    └── WindowSill / Shelf / CherryTree / PottingBench
```

这些节点位于背景渲染对象下方，以背景坐标放置并随画幅适配。动画只变形各装饰自身的网格或移动天气对象，不移动 `PuzzleProps`。后续可在相应挂点下放置解谜道具，或停用、替换某个独立装饰物件，无需重新制作整张动画背景。本次仅提供挂点，没有添加新的解谜机制。

在环境预制体的 `LevelEnvironmentAnimation` 中可设置自动播放、播放速度、粒子数量、天气类型和阵风间隔。在每个 `EnvironmentSwayLayer` 中可调整固定区域、摆动幅度和频率。幅度按图层宽度比例计，频率按每秒循环次数计；参数提供中文提示。阵风配置会自动保留至少三秒静止时间。

动画使用独立时间，玩法时间缩放为零时仍可播放。图层与天气均无碰撞体，渲染于棋盘和动物后方；隐藏或释放 Grid 时一同隐藏或释放。网格变形使用各实例的副本，不修改持久化网格资产。

新增素材由内置 image_gen 生成，完整提示词保存为 `animation-prompts.json`。透明图集由 Unity 切分，风摆网格由编辑器工具生成。首次导入改为读取图片原始尺寸设置 PPU，避免默认导入缩放造成独立图层错位。

新增菜单 `ET/Puzzle/Validate and render environment animations` 会安装资源、生成预览并检查固定区域、解谜挂点、碰撞数量、粒子池复用、启停和阵风间隔。输出位于 `ArtOutput/LevelScenes_Animated_20261101/`；其中动画预览由 Unity 逐帧渲染后封装为动态 WebP，不是预绘制动画帧替代运行逻辑。

## Unity 集成

- `Grid1001.prefab` 引用三个主题，由 `LevelSceneArt` 显示环境和棋盘底垫。
- `GridViewSystem.Awake` 按真实关卡配置 ID 选择主题；1004 及之后的关卡继续使用原有外观。
- `SlotViewSystem.Awake` 在网格隐藏加载时仍能找到父级美术组件，按 `AllowPlace` 选择普通地格或障碍外观。
- 原有 `Square` 的 Sprite、尺寸和 BoxCollider2D 保留。美术使用单独的子渲染器，避免修改吸附尺寸；环境本身不带碰撞体。
- 相机为两侧待拼区预留操作边距；退出关卡时还原相机位置和正交尺寸。背景按相机画幅铺满。
- 环境随 Grid 停用和销毁；正常返回选关无需单独清理背景对象。

`Level1001.prefab`、`Level1002.prefab`、`Level1003.prefab` 是从当前关卡 JSON 生成的独立美术预览，包含相机、九个槽位和现有动物预制体。可放入空场景查看；预览不启动 ET 玩法。预览资源位于 Resources 目录外。

可用菜单：

1. `ET/Puzzle/Install first three level environments`：重新配置图片导入和 Grid 引用。
2. `ET/Puzzle/Render first three level environments`：安装后在隔离预览场景渲染三种画幅，并生成预览预制体。该操作不切换当前打开的场景。
3. 修改 HotfixView 后执行正常的 `ET/Loader/Compile`（F6），再进入 Play Mode；运行时加载的是热更 DLL。
