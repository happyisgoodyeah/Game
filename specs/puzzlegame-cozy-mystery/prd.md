# 产品需求与验收

## 1. 文档状态与目标

- 文档状态.status：`draft`。
- 主文档：[[PuzzleGame/玩法策划/暖日小院/gdd|游戏玩法策划]]。
- 交互依据：[[PuzzleGame/玩法策划/暖日小院/interaction|交互逻辑与状态]]。
- 本次交付为文档；以下需求均为拟议原型范围，不表示已经开发完成。

产品目标：验证“动物行为改变拼图条件”是否能形成清楚、温暖、有惊喜的轻解谜体验。首轮交付目标是三个可玩样关，不扩展成长经济与大型内容生产。

默认场景：鼠标点击、拖拽的离线原型；触屏兼容设计但首发平台未定。P0只保存已完成关卡，不承诺中途局面恢复。

### 成功指标

1. 功能正确：三关至少各有一个合法覆盖解；取物无重复、变形无旧占位、重开可恢复。
2. 因果清晰：5名首次试玩者中至少4人能在第01关90秒内完成取物，最多使用一级提示；第02关后至少4人能说明托盘与盘内旋转的区别。
3. 操作轻松：玩家没有必须快速点击或等待隐藏计时器的步骤，提示不扣资源，错误尝试不受惩罚。

以上为待测原型门槛，不是实测结果或统计结论。

### 非目标

P0不做随机关键掉落、付费提示、体力、星级竞争、全套装修、多人或服务端经济。不开展全工程框架重构。不生成正式视觉稿；不将玩法初稿视为界面风格已批准。

## 2. 用户与使用场景

| 用户场景 | 需要 | 对应策略 |
| --- | --- | --- |
| 首次接触 | 理解盘外也能互动 | 第01关只给一条明显关系，线索来自环境与动物 |
| 解谜卡住 | 不希望乱拖或被惩罚 | 主动查看三级提示，撤销、重开始终可用 |
| 慢速操作或关闭声音 | 能完整获得信息 | 无手速门槛，线索不只用声音，文字与形状反馈并存 |
| 中途离开 | 明白哪些会保留 | 返回前说明本局重置、已通关进度保留；续玩列P1 |
| 重玩关卡 | 欣赏已知互动 | 允许重玩，短演出可简化，不重复产生永久奖励 |

## 3. P0：必须实现的原型需求

| ID | 需求 | 承接页面或组件 | 可检查的验收标准 |
| --- | --- | --- | --- |
| P0-01 | 关卡进入与恢复 | `level-select`、`puzzle-play` | 只进入一局；加载中重复点击无效；失败可重试；重开恢复初始规则状态 |
| P0-02 | 网格放置与90°旋转 | `puzzle-play` | 越界、重叠、禁止格均拒绝；盘内非法旋转恢复旧数据与视图；四次合法旋转回到原方向 |
| P0-03 | 狗与草丛互动 | `puzzle-play/environment` | 合法释放后只生成一只1×1飞盘；狗不消耗且回托盘；重复触发无新增 |
| P0-04 | 短猫、长猫状态 | `puzzle-play/tray` | 托盘短猫四次有效旋转后2格变3格；无时间窗；盘内、非法与动画中点击不计数；同一猫身份保留 |
| P0-05 | 已解锁形态切换 | `puzzle-play/tray` | 仅托盘可蜷起或伸展；长形不因等待消失；不得产生第二只猫或继续增长 |
| P0-06 | 主线线索与三级提示 | `puzzle-play`、`hint-sheet` | 每个必经发现至少有环境与角色两类线索；提示按观察、关联、动作逐级展示；免费无限查看 |
| P0-07 | 有限撤销与重开 | `puzzle-play`、`leave-dialog` | 最近20个有效步骤可撤销；互动为完整事务；历史空时按钮禁用；重开不清除已保存通关记录 |
| P0-08 | 三个样关与组合依赖 | `puzzle-play` | 使用GDD第9节的形状集合；第三关移开猫才开放草丛；两种主机制无循环依赖 |
| P0-09 | 联合通关判定 | `puzzle-play`、`level-complete` | 可放置格全覆盖、必放块全入盘、必经发现完成、无未结束事务；满足一次只结算一次 |
| P0-10 | 结算与进度保存反馈 | `level-complete` | 成功只记录一次通关；保存失败留在结算并可重试或明确选择暂不保存返回；不得显示“已保存” |
| P0-11 | 输入与反馈可读性 | `puzzle-play`、`settings-panel` | 一次释放只进入一个目标分支；反馈以100毫秒内开始为目标；静音、减少动效不改变谜题结果 |
| P0-12 | 生命周期清理 | `puzzle-play`、`level-select` | 返回、重开后旧演出不能给新局发奖励；版本或会话标识阻断过期回调 |

## 5. 信息架构与页面范围

本轮是对现有选关和游戏界面的扩展，不另建复杂主城。页面ID用于需求追踪，不要求把每个弹层实现为独立YIUI面板。

| screen-id | 页面或层 | 本轮内容 | 对应需求 |
| --- | --- | --- | --- |
| `level-select` | 现有选关界面 | 关卡状态、进入、加载失败恢复 | P0-01、P0-12 |
| `puzzle-play` | 现有游戏界面扩展 | 拼图盘、托盘、互动区、目标、撤销、重开、提示、返回 | P0-01—09、P0-11—12 |
| `hint-sheet` | 同页提示层 | 三级线索、关闭、重复查看 | P0-06 |
| `level-complete` | 同页结算层 | 小演出、保存状态、重试、下一关、返回选关 | P0-09—10 |
| `leave-dialog` | 同页确认层 | 重开、中途离开、保存失败后离开时的明确后果 | P0-07、P0-10 |
| `settings-panel` | 现有设置界面扩展 | 静音与减少动效，返回原位置 | P0-11 |

首屏必须能看到至少一个可行动线索、完整目标盘、当前可用拼块的入口。提示层不遮住全部相关对象；减少动效为设置偏好，无须另建新页面。

## 6. 配置与状态依赖

以下是设计字段建议，不是已存在的API或生成代码。

| 数据 | 用途 | 空态或异常处理 |
| --- | --- | --- |
| 关卡配置ID、目标格、初始拼块、必放集合 | 初始化、面积核对与通关 | 配置缺失不进入半成品关卡，返回选关并提示重试 |
| 形态ID、格偏移、旋转、位置、稳定拼块ID | 猫变形、撤销与覆盖预览 | 资源和占格准备完再提交，失败恢复旧形态 |
| 互动规则ID、动物标签、区域、前置条件 | 狗取物与第三关入口揭示 | 条件未满足时给出具体角色反馈 |
| 已完成规则、奖励拼块ID、本局会话版本 | 防刷奖励、防跨局回调 | 不能只存“已领取”而遗漏奖励实体 |
| 猫旋转计数、长形是否解锁 | 托盘进度与形态按钮 | 次数只取0—4，解锁后不继续累加增长 |
| 最近20步完整状态快照 | 事务撤销 | 缺少历史时禁用撤销；仍可重开 |
| 三级提示文案与关联对象 | 帮助继续 | 没有下一层时显示已全部展开，不出现付费入口 |
| 通关进度、保存结果 | 选关解锁与重启读档 | 失败明确标记“尚未保存”，保留重试能力 |

关卡不依赖在线请求，离线不是失败态。P0没有钱包、资源不足或冷却耗尽状态。

## 7. 边界、异常与一致性要求

1. **动作原子性：**取物同时改变狗位置、规则标记和飞盘存在性；形态变化同时更新数据格、碰撞和视图。不能出现部分成功。
2. **回弹口径：**普通非法放置返回拖拽开始时的合法状态；该状态可以是原棋盘位置或托盘位置。这是拟议的新体验要求，不能假定现有回原位方法已经满足。
3. **资源失败：**奖励或新形态资源失败时取消该次结果并允许重试，不吞动物、不吞次数、不凭空记录完成。
4. **第三关入口：**首次有效移开猫后入口持续开放；撤销揭示步骤才恢复关闭。不能仅依靠当前猫是否站在某个像素坐标动态开关。
5. **撤销顺序：**后产生的飞盘若已入盘，先撤销它的放置，再撤销取物事务；不得删除飞盘却留有它的格占位。
6. **快速操作与串行事务：**P0同时只执行一个改变局面的事务。取物或变形提交、回滚完成前，全局阻断拼块拖拽、旋转、撤销和重开，提示与设置可查看；改变偏好不能打断正在提交的状态。输入不排队补发。完整提交后的装饰性尾声不阻断局面操作，避免完整快照回滚覆盖其他动作。
7. **返回与重开：**取消或隔离本局未完成异步操作。完成事务后的旧局回调不能作用于新关卡。
8. **保存失败：**已有代码检查保存结果但仍返回选关；P0新增玩家可见的失败、重试和暂不保存离开路径。临时未保存的会话进度不能显示为已持久化。
9. **持久化范围：**P0只存通关进度；若实现触及存档结构，分别验证编辑器JSON与发布版MemoryPack，并明确旧档兼容。P1局内续存不能单存棋盘漏掉谜题状态。

## 8. 验收用例

### 玩法与提示

- [ ] 第01关初始8格不能覆盖9格；取得飞盘后可按GDD示例完成；狗与飞盘都必须入盘。
- [ ] 草丛未开放、错误动物、释放在热点外都有可理解的反馈，且不会消耗或丢失拼块。
- [ ] 同一飞盘反复触发10次仍只有一个；取物演出中快速点击也不重复。
- [ ] 第02关托盘短猫转1、2、3次分别显示进度；第4次变3格，四次间可任意停顿。
- [ ] 盘内合法旋转、非法旋转均不积累猫的变形进度；长形点击不再增加面积。
- [ ] 猫可在托盘切回短形再伸展；身份与已解锁状态不丢失。
- [ ] 第03关猫未移开时取物被明确拒绝；移开后入口开放；先变猫或先取飞盘都能完成。
- [ ] 三级提示能从模糊观察逐步达到明确动作，不扣资源、不影响评价。

### 放置、恢复与生命周期

- [ ] 首次进入、3×4非正方形盘、拖拽吸附、越界和占位拒绝均正常。
- [ ] 四次合法旋转回到原覆盖形状；非法旋转恢复占位与朝向，未产生重复绑定。
- [ ] 从盘内拿起后错误释放，回到拿起前位置；托盘错误释放回到托盘。
- [ ] 撤销取物恢复狗、飞盘与规则；撤销伸展恢复形态、方向与次数。
- [ ] 20步历史边界可预测；空历史不报错，重开恢复本关初始局面。
- [ ] 演出、加载期间重开或返回，不产生旧局实体访问或新局重复奖励。

### 完成与存档

- [ ] 格子填满但必经发现未完成、必放块未入盘或事务未结束时，不提前通关。
- [ ] 正常完成、连续点击与重玩已通关关卡只触发一次该局结算。
- [ ] 保存成功后重启，选关通关与解锁状态仍存在。
- [ ] 模拟保存失败，结算留在`saving-failed`；重试成功更新为`saved`；暂不保存返回有明确提示。
- [ ] 涉及存档修改时，JSON与MemoryPack分别完成保存读取，记录旧档策略与实际结果。
- [ ] 静音、减少动效后，所有关键线索与奖励结果仍可理解。
